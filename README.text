# ⚡ Piezoelectric Properties of Wurtzite AlN using VASP

First-principles calculation of **piezoelectric properties**, **elastic tensor**, **dielectric tensor**, **piezoelectric strain tensor (dij)**, and **electromechanical coupling tensor (kij)** of wurtzite AlN using Density Functional Theory (DFT) and VASP.

---

## 🎯 Overview

Piezoelectric materials convert mechanical deformation into electrical polarization and vice versa, making them essential for:

- Sensors
- Actuators
- MEMS/NEMS devices
- RF filters
- Energy harvesting
- Wearable electronics

In this tutorial, we demonstrate a complete workflow for calculating piezoelectric properties of **wurtzite AlN**, one of the most important lead-free piezoelectric semiconductors.

---

## ⭐ Key Findings

- Strong longitudinal response:
  
  ```
  d33 = 5.03 pC/N
  ```

- Significant transverse response:

  ```
  d31 = d32 = -2.10 pC/N
  ```

- Good shear response:

  ```
  d15 = -2.57 pC/N
  d24 = -2.45 pC/N
  ```

- Moderate electromechanical coupling:

  ```
  k33 = 0.331
  ```

- Tensor symmetry consistent with hexagonal wurtzite AlN.
