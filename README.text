# Piezoelectric Properties of Wurtzite AlN using VASP

This repository provides a complete workflow for calculating the **piezoelectric properties** of **wurtzite AlN** using **Density Functional Theory (DFT)** with **VASP**.

The tutorial demonstrates how to calculate the **elastic tensor**, **dielectric tensor**, **piezoelectric stress tensor**, **piezoelectric strain tensor (dij)**, and **electromechanical coupling tensor (kij)**, together with the interpretation of these properties for practical piezoelectric applications.

---

# 📚 Overview

Piezoelectric materials convert **mechanical stress into electrical polarization** and vice versa. These materials play a critical role in modern electronic devices including sensors, actuators, resonators, RF filters, and energy harvesting systems.

Among various piezoelectric materials, **wurtzite AlN** is widely used because of its:

* Lead-free composition
* High thermal stability
* Excellent chemical resistance
* Wide band gap
* High breakdown field
* CMOS compatibility
* Good piezoelectric performance

This repository presents a complete first-principles workflow for calculating these properties using **VASP**.

---

# 🔬 Workflow

The tutorial covers the complete computational workflow:

* Crystal structure preparation
* Geometry optimization

* Elastic tensor calculation
* Dielectric tensor calculation

# ⭐ Key Features

* Strong longitudinal piezoelectric response (**d₃₃ = 5.03 pC/N**)
* Significant transverse response (**d₃₁ = d₃₂ = -2.10 pC/N**)
* Good shear response (**d₁₅ = -2.57 pC/N**, **d₂₄ = -2.45 pC/N**)
* Moderate electromechanical coupling (**k₃₃ = 0.331**)
* Tensor symmetry consistent with the hexagonal wurtzite crystal structure
* Complete workflow using first-principles calculations
